GitHub

{{if eq .GitHubEnabled "1"}}Enabled{{else}}Disabled{{end}}
Setup steps
  1. Go to github.com → Settings → Developer settings → OAuth Apps → New OAuth App
  2. Set Authorization callback URL to the GitHub callback URL above
  3. Copy the Client ID and generate a Client secret
  4. Paste them here, check Enable, and save
Scope requested: user:email

Google

{{if eq .GoogleEnabled "1"}}Enabled{{else}}Disabled{{end}}
Setup steps
  1. Open console.cloud.google.com → APIs & Services → Credentials → Create credentials → OAuth client ID
  2. Choose Web application
  3. Add the Google callback URL above under Authorized redirect URIs
  4. Copy the Client ID and Client secret, paste them here, check Enable, and save
Scopes requested: openid email profile

Discord

{{if eq .DiscordEnabled "1"}}Enabled{{else}}Disabled{{end}}
Setup steps
  1. Go to discord.com/developers/applications → New Application
  2. Under OAuth2, add the Discord callback URL above as a redirect
  3. Copy the Client ID and Client secret from the OAuth2 page
  4. Paste them here, check Enable, and save
Scopes requested: identify email
